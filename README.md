# EcomBoost AI for Claude

Ask Claude how your Shopify store is doing and have it build what you need to sell more, using your real data: revenue leaks, sales, stock, ads, landing pages, sales content, product imports, AI-shopping readiness, and whether past changes worked.

The plugin is free. It never changes your store on its own: every change is shown to you as a before/after first and is applied only after you say yes (publishing changes needs a paid plan).

## Install

Store roasts need no account. To also use your private sales data, do step 1 and step 3.

1. [Create a free EcomBoost AI account](https://www.ecomboostai.com/signup?utm_source=claude_plugin&utm_medium=github) and connect your Shopify store.
2. Install the plugin in Claude Code:

   ```
   claude plugin marketplace add addielmercedes9-glitch/ecomboost-claude-plugin
   claude plugin install ecomboost-ai@ecomboost-ai
   ```

3. Start a session, run `/mcp`, and sign in to `ecomboost`.

Using claude.ai? [Add the connector](https://www.ecomboostai.com/claude-connector) instead.
